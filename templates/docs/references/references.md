# Referensi desain

Diisi owner sebelum proyek dimulai. Simpan semua file gambar di folder ini.
Referensi adalah **sumber prinsip, bukan untuk disalin**.

## Format yang bisa diproses agent
| Bentuk | Format | Catatan |
|---|---|---|
| Screenshot | PNG, JPG, WebP | Satu file per section (hero, grid, footer). Lebar desktop ±1440px, tambah mobile bila ada. Hindari screenshot full-page yang sangat panjang. |
| Gerak/animasi | 3–4 screenshot berurutan + deskripsi tertulis | Tulis: apa yang bergerak, arahnya, kapan terpicu (load/scroll/hover), perkiraan durasi. |
| Situs | URL | Untuk dicek ulang; animasi tidak terbaca dari URL saja. |
| Dokumen | PDF | Brand guideline, moodboard. |
| Desain sendiri | Link Figma | Hanya bila connector Figma tersambung; selain itu ekspor PNG. |
| **Tidak bisa diproses** | Video saja, link Instagram/TikTok, gambar di balik login | Ganti dengan screenshot + deskripsi. |
