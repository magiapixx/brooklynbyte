# Assets

The 29 raster slots in `src/assets/images/` now use varied blue-and-white sculptural renders inspired by the owner's Unsplash reference, [Abstract, spiraling sculpture with blue and white tones](https://unsplash.com/photos/sJ_nxQIAUvg). The set favors flowing, folded, spiral, and layered forms over hard geometric cubes. Each image is stored locally as WebP, with dimensions chosen for its display role and each file below the 200 KB raster limit. Unsplash photo pages and the standard license are linked per asset. No AI-generated images or new dependencies were used.
